دفتر معین حسن‌بیگی — نسخه آزمایشی آفلاین + فضای ابری

فایل‌ها:
- index.html / app.js: برنامه
- manifest.json / sw.js / icon.svg: نصب‌پذیری و حالت آفلاین
- supabase-setup.sql: ساخت جدول و سیاست‌های امنیتی فضای ابری

راه‌اندازی رایگان فضای ابری:
1) در supabase.com یک حساب بساز و New project را انتخاب کن.
2) در پروژه، SQL Editor را باز کن، محتوای supabase-setup.sql را اجرا کن.
3) از Project Settings > API، مقدار Project URL و کلید anon/public یا publishable را بردار.
4) برنامه را روی HTTPS میزبانی کن (مثلاً GitHub Pages رایگان). فایل‌ها را در یک مخزن GitHub بارگذاری و از Settings > Pages فعال کن.
5) برنامه را باز کن، در صفحه ورود Project URL و کلید عمومی را در تنظیمات وارد و ذخیره کن؛ سپس با ایمیل و رمز عبور حساب بساز.
6) برای نصب در آیفون: در Safari آدرس برنامه را باز کن > Share > Add to Home Screen.

نکات امنیتی:
- فقط کلید anon/public یا publishable را در برنامه قرار بده. هرگز service_role/secret key را وارد نکن.
- جدول با Row Level Security تنظیم شده و هر کاربر فقط ردیف‌های خودش را می‌بیند.
- رمز عبور نزد برنامه ذخیره نمی‌شود؛ مدیریت ورود با Supabase Auth است.
- پیش از استفاده واقعی، از بخش پشتیبان‌گیری خروجی JSON بگیر.

محدودیت‌های این نسخه:
- آفلاین روی همان دستگاه کار می‌کند؛ همگام‌سازی ابری هنگام اتصال اینترنت انجام می‌شود.
- این نسخه برای شروع، موجودی را بر اساس جمع خرید منهای فروش نشان می‌دهد. محاسبه سود دقیق و حسابداری دوطرفه/چک‌های کامل هنوز پیاده‌سازی نشده و نباید سود آن را مبنای حساب نهایی قرار داد.
- پس از بارگذاری اولیه روی HTTPS، پوسته برنامه در دسترس آفلاین قرار می‌گیرد. ورود و همگام‌سازی ابری به اینترنت نیاز دارد.
